# Test data (synthetic)

All values are invented, generated by `tests/generate_test_data.py` (fixed seed, so re-running gives identical files). No names, birth dates, real codes, or real organizations. Members are identified by ID and birth year only.

## Files by workflow

| File | Rows | Used in | Columns |
| --- | --- | --- | --- |
| `members.csv` | 40 | WF1, WF2, WF4 | member_id, birth_year, region, plan_type, status, enroll_date, term_date |
| `cases.csv` | 60 | WF2, WF4 | case_id, member_id, program, open_date, close_date, status, navigator_id |
| `cases_2026_07.csv` | 18 | WF3 | case_id, member_id, program, open_date, status |
| `cases_2026_08.csv` | 20 | WF3 | case_id, member_id, program, open_date, status |
| `cases_2026_09.csv` | 22 | WF3 | case_id, member_id, **program_name**, open_date, status |
| `claims.csv` | 60 | WF4 | claim_id, member_id, case_id, service_date, proc_code, allowed_amount, steered_flag, navigator_note |
| `benchmarks.csv` | 10 | WF4 | proc_code, benchmark_cost |

## Planted data quirks

| File | Quirk | What it tests |
| --- | --- | --- |
| `members.csv` | `term_date` blank for active members; 14 members born 1961 or earlier | Null handling; age-band logic |
| `cases.csv` | `close_date` blank for 20 open cases | Date difference with a null end date |
| `cases_2026_07.csv` | Dates as `MM/DD/YYYY` text | Date parsing |
| `cases_2026_08.csv` | Dates as ISO `YYYY-MM-DD`; one row with blank `member_id` | Mixed formats across a Union; null keys |
| `cases_2026_09.csv` | Dates as `DD-Mon-YYYY`; column renamed to `program_name`; status in lowercase; cases C2103 and C2106 repeated from August | Union by name vs. position; case sensitivity; duplicates |
| `claims.csv` | 6 amounts stored as currency text (`"$11,012.14"`) | Type conversion |
| `claims.csv` | Navigator notes: standard `Ref NAV-2026-0255`, 7 lowercase unpadded `ref#nav-2026-7`, 2 with no reference | RegEx robustness |
| `claims.csv` + `benchmarks.csv` | 2 claims use `PROC-111`, which has no benchmark | Unmatched join records (L/R outputs) |
